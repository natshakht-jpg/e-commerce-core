# E-commerce Core

## Описание

Ядро для интернет-магазина. Реализованы базовые классы для работы с товарами и категориями.

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
```
poetry install
```
## Использование

from src.product import Product
from src.category import Category

### Создание товаров
product1 = Product("Ноутбук", "Мощный ноутбук", 50000.0, 5)
product2 = Product("Мышь", "Беспроводная мышь", 1500.0, 10)

### Создание категории с товарами
category = Category("Электроника", "Товары для дома", [product1, product2])

## Загрузка данных из JSON
В проекте реализована функция `load_from_json` в модуле `utils.py`, которая позволяет загружать категории и товары из JSON-файла.

Пример использования:
```
from src.utils.utils import load_from_json

categories = load_from_json("data/products.json")
```

### Добавление нового товара в категорию
product3 = Product("Клавиатура", "Механическая", 3000.0, 7)
category.add_product(product3)

### Просмотр товаров в категории (геттер)
print(category.products)
# Вывод:
# Ноутбук, 50000.0 руб. Остаток: 5 шт.
# Мышь, 1500.0 руб. Остаток: 10 шт.
# Клавиатура, 3000.0 руб. Остаток: 7 шт.

### Создание товара из словаря (с проверкой дубликатов)
data = {"name": "Ноутбук", "description": "Игровой", "price": 55000.0, "quantity": 2}
new_product = Product.new_product(data, [product1, product2, product3])
# Если товар с таким именем уже есть — обновится количество и цена

## Документация

В проекте реализованы:
В проекте реализованы:
- Класс Product с атрибутами: name, description, price, quantity
- Класс Category с атрибутами: name, description, products
- Автоматический подсчет количества категорий и товаров
- Приватные атрибуты `__products` и `__price` для защиты данных
- Метод `add_product` для добавления товаров в категорию
- Геттер `products` для получения списка товаров в формате "Название, цена руб. Остаток: шт."
- Класс-метод `new_product` для создания товаров из словаря (с обработкой дубликатов)
- Геттер и сеттер для цены с проверками (защита от отрицательных цен, подтверждение понижения
- - Магические методы в классе Product:
  * `__str__` — возвращает строку "Название, цена руб. Остаток: количество"
  * `__add__` — возвращает сумму price * quantity для двух продуктов
- Магические методы в классе Category:
  * `__str__` — возвращает строку "Название категории, количество продуктов: X шт." (сумма quantity всех товаров)
- Итератор `CategoryIterator` для перебора товаров категории в цикле for
- - **Наследники класса Product:**
  * `Smartphone` — добавлены атрибуты: efficiency (производительность), model (модель), memory (объем памяти), color (цвет)
  * `LawnGrass` — добавлены атрибуты: country (страна-производитель), germination_period (срок прорастания), color (цвет)
- В метод `__add__` добавлена проверка типов (нельзя складывать товары разных классов)
- В метод `add_product` добавлена проверка `isinstance` (можно добавлять только объекты Product и его наследников)
- **Класс-миксин `ProductPrintMixin`** — печатает информацию о создании объекта
- **Абстрактный класс `BaseContainer`** — общий предок для `Category` и `Order`
- **Класс `Order` (Заказ)** — содержит товар, количество и итоговую стоимость
- В `Category` добавлены методы `total_quantity()` и `total_price()`
- Создано пользовательское исключение `ZeroQuantityError` для товаров с нулевым количеством.
- В конструкторе `Product` добавлена проверка: если количество = 0, выбрасывается `ZeroQuantityError`.
- В методе `add_product` класса `Category` добавлена обработка этого исключения с сообщениями:
  * При ошибке — «Ошибка: Товар с нулевым количеством не может быть добавлен»
  * При успехе — «Товар успешно добавлен»
  * В любом случае — «Обработка добавления товара завершена»
- Написаны тесты, общее покрытие — 100%.
